Experiment firmwares
====================

Besides ``train``, the build produces small firmwares used to learn about the
hardware. They run with the SPL fragment ``configs/k3_freefw_probe.config`` (or
a dedicated one), which stops the SPL after the PMU run without activating the
DDRC:

.. code-block:: sh

   make fsbl FW=<name> [FSBL_FRAG=configs/<fragment>.config]
   tools/bench.sh build/fsbl-<name>/FSBL.bin <run-name>

``probe`` (``src/probe/main.c``)
   Streams IDENTITY and the ARCv2 build configuration registers, RTC samples
   for the tick rate, the message block, ISA self tests and an IMEM data read.
   Experiments :exp:`000` and :exp:`001`.

``csrdump`` (``src/csrdump/main.c``)
   Read-only: reads the 5170 ``phypara`` CSRs (compact table generated by
   ``tools/gen_phypara.py --fw``) and the 4096 ACSM halfwords from the PMU side
   into DMEM ``0x80008000`` (host index ``0x5c000``) and streams a summary
   (``LOG_ID_CSRDUMP``). With ``K3_DDR_PMU_COMPARE_DUMP`` the SPL compares that
   copy with its own reads and prints all values; ``tools/dump_extract.py``
   turns the log into CSV. Fragment ``configs/k3_freefw_csrdump.config``.
   Experiment :exp:`002`.

``csrscan`` (``src/csrscan/main.c``)
   Read-only scan of whole index ranges (groups ``0x02``, ``0x04`` control,
   ``0x0c``); the index being read is kept in breadcrumb slots 14/15 so a
   stalling read can be identified. ``tools/scan_extract.py`` builds CSV files
   annotated with the host-table value. Experiment :exp:`004`.

``pllprobe`` (``src/pllprobe/main.c``)
   **Writes** the PLL registers of a DDR4 variant of the PHY, powers the PLL
   up and watches lock and period counters with timestamps. Experiment
   :exp:`005` showed those registers do not exist on the K3; the probe is kept
   only as the record of that experiment.

``train`` as an experiment vehicle
   The training firmware itself carries the quickboot path and the RdDQS
   probe; which one runs is chosen by the message block (``Quickboot``,
   ``SequenceCtrl``, flag ``0xa5`` in byte 0) and by the SPL fragment
   (:doc:`../uboot-spl/quickboot-host`). Experiments :exp:`011`–:exp:`019`.

Rules for experiment firmwares
------------------------------

* Start read-only; any register write is a separate, documented experiment.
* Keep ``.bss`` below the buffers they publish to the host (checked at run
  time by ``csrdump``).
* Use major codes ``0x20``–``0x2f`` and stream IDs ``0x0810``–``0x08ff``.
